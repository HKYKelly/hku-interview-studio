# 赴港练习室

面向港大 CS 与 MSc AI 笔面试的中文学习项目。当前版本按用户提供的面经考点编写，包含 20 张知识题卡、80 道选择练习和 22 个面试问题。

## 本地启动

安装 Node.js 20 或更新版本。在项目文件夹运行以下命令，再打开 http://127.0.0.1:4173 。

```sh
node server.mjs
```

项目使用原生 JavaScript 模块与 CSS，无需安装依赖。也可使用支持模块的静态网站服务器。麦克风需要 localhost 或 HTTPS 环境。

## 已实现

- 分类题卡、知识点搜索、错题筛选。
- 每卡原理、公式、做题步骤、易错点和可保存草稿。
- 跟着做、独立题、三道变式、逐步提示、答案解释。
- 提示下答对记为辅助练习，重新独立答对后计入完成度。
- 面试独立页面和新窗口入口，按 CS、AI、ECIC 及问题来源筛选。
- 面经转述与推测追问标注，英文语音读题、本地录音、回放、下载、可选浏览器英文转写。
- 面试回答要点自评、预设追问、文字自动保存。
- 学习进度及 JSON 导出备份。

## 当前边界

讲解和追问使用内置教学内容，反馈依赖客观选项答案和自评要点。自由问答、语义评分、发音评分尚未接入模型服务。语音体验由系统朗读与浏览器录音组成。浏览器的语音转写可能依赖供应商联网服务，需要用户勾选启用。录音仅保留在当前页面，文字与题卡进度保存到 localStorage。

本次先合并实现 20 张核心题卡。深入分部积分、反常积分、独立的抽象类与接口专题、完整手写代码执行判题、数据库与谜题还需后续扩充。题卡的三个变式均预先编写。

## 项目结构

- `src/data/curriculum.js` 管理笔试题卡，每张卡四道题，第一题基础、后三题变式。
- `src/data/interviews.js` 管理问题来源、英文题干、中文说明、回答要点及追问。
- `src/app.js` 管理界面、进度与语音生命周期。
- `src/style.css` 管理响应式界面。
- `server.mjs` 提供仅绑定本机的开发预览。

题目为考点改编。来源依据用户提供的 CS、MSc AI、ECIC 面经回忆及旧题考点，未收录原始 PDF、截图、简历或申请材料。推测问题独立标注。
